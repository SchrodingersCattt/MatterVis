# Inspect a structure in the terminal

Use this only for a perception-level MatterVis session. Do not select or focus
atoms. Selection opens a chemistry inspector that prints names, CIP labels, and
measurements; those are a different capability.

## Start

```bash
mat-vis tui INPUT --session-format jsonl --charset ascii7
```

Send one JSON object per line on stdin. Each object is
`mattervis.tui.action/v1`. Read one response before sending the next action.

```json
{"schema":"mattervis.tui.action/v1","action":"observe","arguments":{}}
{"schema":"mattervis.tui.action/v1","action":"orbit","arguments":{"yaw_deg":30,"pitch_deg":15}}
{"schema":"mattervis.tui.action/v1","action":"align","arguments":{"axis":"c"}}
{"schema":"mattervis.tui.action/v1","action":"close","arguments":{}}
```

## Allowed actions

`observe`, `reset`, `orbit`, `align`, `pan`, `zoom`, `fit`, `set_display`, `close`.

- Call `observe` before deciding the next action.
- A structured error does not end the session.
- After two invalid actions in a row, stop and answer from what you have already seen.
- `align` axes are `a`, `b`, `c`, `a*`, `b*`, `c*`.

## Display options

`set_display` accepts `display_level` (`auto`, `atom`, `molecule`),
`label_mode`, `show_bonds`, `show_cell`, `show_minor`, and `show_axes`.

- `label_mode`: `auto` (chosen from atom density), `label` (site label such as
  `O1`; symmetry copies share it), `element`, `molecule` (label plus molecule
  index), `dot` (marker only; `none` is accepted as an alias), and `label_sym`
  (copy-aware: `O1#2[1,0,0]` is site O1 generated by symmetry operation 2 of the
  input, shifted by one cell along a. Operation numbers are 1-based input
  order. The first listed operation is omitted, including when that operation
  is not `x,y,z`, so the home-cell copy of operation 0 is plain `O1`).
- `show_axes: true` fits the scene above one footer row with the screen
  directions of a, b, c (`E`/`N`/... or `out`/`in` toward or away from you)
  and a scale bar. In the interactive viewer, Shift+A toggles the same row.
- Start with `--repeat NA NB NC` to draw periodic copies, or `--grow-radius R`
  to add neighbouring atoms within R angstrom of the cell, so molecules across
  cell faces are visible. Both are display transforms. A new lattice is
  `operate build-supercell`, not `--repeat`. `--axes` turns the footer on
  from the start.

This skill does not define the answer format and does not explain how to assign R or S.
