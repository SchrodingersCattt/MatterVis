# Paper Reproducibility Data

This directory contains figure-generation scripts for MatterVis publication figures.

## Contents

| Directory | Description |
|---|---|
| `showcase/` | README showcase images (unit cell, coordination, ORTEP, three-mode panel, banner) |
| `coordination/` | Coordination topology analysis figures |
| `ortep/` | ORTEP publication figures |
| `cube_orbital/` | Cube/orbital isosurface figures |

## Quick Start

```bash
# Regenerate all README showcase images
python paper/showcase/build_images.py
```

See each subdirectory's `README.md` for detailed instructions.
