# COD UI QA follow-up: #176 and #177

This matrix records the control-level fixes included in the PR. Every row has
either a focused regression test or a concrete before/after behavior note.

| Issue item | Before | After / evidence |
|---|---|---|
| #176 H radius | H used its compact ball-stick radius and could be hidden by a 0.15 Å bond. | H/D uses a 1.5× bond-radius floor by default, with `min_atom_radius` override. Covered by radius/render contract tests. |
| #176 display reset | Persisted display edits had no restore action. | “Restore display defaults” resets display controls and camera for the active scene while preserving structure, transforms, and operations. `tests/app/test_display_defaults.py`. |
| #177 Style | Ball, wireframe, ORTEP, and ball-stick changes could produce the same effective frame. | Style is part of geometry identity and each representation reaches its intended renderer. Existing style/render tests plus geometry clock tests. |
| #177 Atom groups | Monochrome rule could be ignored by the effective color selector. | Effective atom-group rules now drive monochrome output. Existing atom-group renderer tests. |
| #177 Bond groups | A zero-opacity bond rule could still produce a thick visible bond. | Bond-group opacity/radius are carried into the trace identity and rendering path. Existing bond-group tests. |
| #177 Analyze fragment | X0·ClO4 could report the unrelated B0/N2 center. | Selected molecule-level anchor is preserved unless a matching atom-level spec exists. `test_selected_x_fragment_keeps_its_anchor_when_specs_target_cations`. |
| #177 Symmetry transform | Invalid input reached a `NotImplementedError` during rendering without UI feedback. | JSON/shape validation and explicit editor error status; unsupported symmetry is rejected before render. `tests/app/test_transform_validation.py`. |
| #177 rapid updates | Fast slider/bond-group edits could deliver an older frame after a newer build. | Geometry/display/camera clocks reject stale browser updates. `tests/app/test_view_updates.py` and `test_view_updates_js.py`. |
| #177 Disorder only | Ordered structures could still show every atom when “Disorder only” was selected. | Resolve reports no disorder replicas for ordered CIFs; the viewer keeps ordinary atoms visible when no minor traces exist, avoiding an empty canvas. `tests/operations/test_resolve_disorder.py`, `test_disorder_resolve_controls.py`, and `test_display_controls_176_177.py`. |
| #177 camera reset | Reset could leave a zoomed camera in the active tab. | Reset restores the scene-default camera and zoom. `test_camera_reset_restores_default_zoom_after_a_deep_zoom`. |
| #177 colormap/range | Arbitrary colormap names and invalid manual ranges were accepted; Auto cleared visible bounds. | Colormap registry validation, strict finite `min < max`, and derived Auto bounds remain visible. `tests/test_atom_properties.py`. |
| #177 shell labels | Analysis rows displayed unresolved `?(?)` labels. | Shell rows include stable fragment labels/species. `test_molecule_shell_items_have_fragment_labels_and_species`. |
| #177 polyhedra | An unmatched spec could rebind a selected fragment to a giant/unrelated overlay. | Unmatched molecule-level selections keep their anchor; overlays remain viewport-scoped. Polyhedron renderer regressions cover this. |
| #177 BFDH | Max Index 0/-1 were accepted and Top N 0 silently became 10. | Max Index <1 reports an error; Top N <1 intentionally defaults to 10. BFDH analysis/failure tests. |
| #177 Resolve | Counts were not safely bounded; empty random seed reused a cached sample; ordered CIFs could claim replicas. | Counts are bounded to 1–128, seeded calls cache deterministically, unseeded random calls do not, and ordered CIFs return no disorder. Resolve control tests. |
| #177 transforms | Zero Miller index, unknown seed elements, malformed symmetry JSON, and repeat budget errors were silent or renderer-only. | Editor/backend validation returns status errors and keeps the offending rows visible. `tests/app/test_transform_validation.py`. |
| #177 static export | Export button was enabled when `plotly-export` was unavailable. | Button is disabled with the exact install command shown; available exports use explicit local PNG settings. Layout/export capability tests. |
| #177 camera PNG | Plotly mode-bar download used default settings. | PNG download has an explicit local filename, format, scale, and no Plotly logo. Factory layout test coverage. |
| #177 Colour Field | The field control was effectively presented as Element-only. | Dynamic property catalog fields remain selectable, with valid reductions and registry-backed colormap choices. Atom-property UI tests. |
